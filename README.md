**FuelInfo** displays extended info on vanilla Furnaces (including its variants) and Brewing Stands, such as how many items can be smelted, time remaining and how many (sets of) potions can be brewed. 

To use it, simply hover above progress arrows, flame icons and fuel gauges:

![](https://imgur.com/VIR3nTV.png)
![](https://imgur.com/10c2AOf.png)
![](https://imgur.com/5c2VfUL.png)

Additionally, you can hold the Shift key while hovering to alternate how the info is displayed to you.
